# Trabajo Práctico HTML, CSS y JavaScript – UTN

Proyecto grupal realizado en la UTN para practicar el desarrollo web.  
El objetivo fue construir un sitio responsivo que combine **HTML** para la estructura, **CSS** para el diseño y **JavaScript** para la interactividad.

## 🚀 Funcionalidades
- Menú de navegación con enlaces internos.
- Sección *Hero* con título destacado y botón de acción.
- Apartado **Sobre Nosotros** con información del grupo.
- Catálogo de **Prendas más vendidas** con cartas de productos.
- Lista de características principales.
- Sección de carrito con botón de compra.
- Footer con créditos.

## 👥 Trabajo en grupo
Cada integrante se encargó de:
- **HTML:** estructura y semántica del sitio.
- **CSS:** estilos, colores y disposición visual.
- **JavaScript:** funciones de interacción y dinamismo.

## 🛠️ Tecnologías utilizadas
- HTML5
- CSS3
- JavaScript
